## Projetos em destaque

### [pizzaUP](https://github.com/vulgotaj/pizzaUP)

Sistema full stack para gerenciamento de pedidos de uma pizzaria, com API REST e painel administrativo web. Projeto em desenvolvimento.

- Cadastro e autenticação com JWT, com controle de acesso por perfil.
- Gerenciamento de categorias, produtos com imagens e fluxo de pedidos.
- Tecnologias: Next.js, React, TypeScript, Tailwind CSS, Node.js, Express, Prisma e PostgreSQL.

[Ver código e documentação](https://github.com/vulgotaj/pizzaUP)

### [DevControle](https://github.com/vulgotaj/DevControle)

Projeto de estudo para gerenciar clientes e chamados de suporte, com dashboard administrativo e uma área pública para abertura de chamados.

- Autenticação de usuários e gerenciamento de clientes e chamados.
- Formulários com validação e persistência de dados em MongoDB.
- Tecnologias: Next.js, React, TypeScript, Tailwind CSS, React Hook Form, Zod, NextAuth e Prisma.

[Ver código e documentação](https://github.com/vulgotaj/DevControle) · [Acessar demonstração](https://dev-control-wheat.vercel.app)
